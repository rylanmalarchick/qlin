Benchmark sources
=================

benchmarks/hand/
  Hand-written programs. mbqc_chain4 and decode_reset are written to
  exercise the M0 moves (two-armed Ifs). They are not drawn from a suite.

benchmarks/jeff/src/*.jeff
  From github.com/unitaryfoundation/jeff, benchmarks/structured,
  commit 32c323585792d8d30426a6550be9032ef5b0f3ae (2026-09-21).
  Apache License 2.0, copy in benchmarks/jeff/src/LICENSE.

benchmarks/jeff/*.qlin
  Output of `qlin import` (default --max-iters 8) on each file above.
  Files that do not import have no .qlin. The test
  tests/import_jeff.rs checks that each .qlin matches a fresh import.

benchmarks/dynamarq/*.qlin
  Output of bench/export_dynamarq.py on dynamarq
  (github.com/sumeetshirgure/dynamarq, commit
  cd6306c6749d97d8b4ab4b20ee500c147ec0735a, MIT) with mcm=True.
  qiskit_ibm_runtime MidCircuitMeasure is written as `measure`.
  Barriers are dropped. For the gate benchmarks (fanout, long-range CNOT,
  CNOT ladder) only the first direct-fidelity-estimation sample is kept.

benchmarks/dynamarq/*_noisy.qlin
  The QEC circuits with a random X error on each data qubit (probability
  0.05), placed just before the first gate on a syndrome ancilla. The last
  qubit is the noise source: ry, measure, `if e { x dI }`, reset, once per
  data qubit. Metrics use `qlin stats --noise-qubits LAST` so the
  injection ops do not count.
